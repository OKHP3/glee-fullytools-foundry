The owner selected the merged vector artwork as the canonical cover and social-card direction. New FoundRy image treatments should remain consistent with that set rather than replacing it with the unselected photo-based direction.

**Why:** The owner chose the existing vector set to avoid competing cover and social-card styles.

**How to apply:** Preserve the canonical vector artwork and use compatible derivatives when adding new application imagery.
