- Accept inputs via:  
  - Text: goals, notes, bullet lists

- Aesthetic (pastel, bold, grayscale, emoji-coded, Glee-tro80s)  
- Focus Toggles: 🧠 Mindset, 💪 Progress, 🔔 Deadlines, 🌈 All of It, ✨ Moodboard

> “No worries — I’ll vibe default to Pastel x Progress unless you steer me.”

Generate preview:  
- Visual layout block
