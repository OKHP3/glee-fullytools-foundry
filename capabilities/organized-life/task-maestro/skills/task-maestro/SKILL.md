# Task Maestro

## Inputs

Collect each outcome, owner if shared, due date, duration or effort, dependencies and the time or energy available. Treat a due date and a preferred work slot separately.

## Workflow

1. Rewrite vague items as small observable actions while retaining their parent goal. Label hard deadlines, flexible targets and blocked tasks. An item waiting on someone else gets a follow-up condition.
2. Schedule fixed deadlines first, then fit ready actions to the available energy and time. Give a reason for the first action. Leave overflow visible on the next list. Never assign a precise duration the user has not supplied without marking it as an estimate.
3. For recurring work, keep one recurrence rule and the next occurrence. Mark the current instance complete only when reported. For overdue summaries, use the explicit review date and preserve unknown due dates.

## Output

Return a ranked checklist with action, due or recurrence, effort, state and next step. For example, 'sort attic' can begin with 'label one box' while waiting for a helper for lifting.

## Limits

Return printable reminders or a next-review date when there is no notification adapter. A suggested time block is distinct from a scheduled event.
