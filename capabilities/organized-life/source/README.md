# Glee-fully Organized Life

This repository is the #05 Organized Life branch of the Glee-fully suite.

## Current status

This is an early-stage documentation and Agent Skill workbench. It does not
contain an implemented application, user interface, data store, integration,
deployment target, or production runtime.

The original project direction covers personal tasks, spending, gifts,
scheduling, lifestyle visibility, and neighborly exchange. The current
checkout also contains project-local skills and prompts used for AI workflow
authoring, migration, evaluation, and repository maintenance.

## Repository map

- `AGENTS.md` is the canonical repository guide.
- `.agents/prompts/` contains project onboarding, migration, and context
  bootstrap prompts.
- `.agents/skills/` contains the active project-local Agent Skill surface.
- `skills/` contains the promotion source package for
  `okhp3-skill-promotion`.
- `archive/` contains historical project directive material that is no longer
  active guidance.
- `LICENSE` contains the MIT license.

The generated skill catalog in `.agents/skills/README.md` is the best starting
point for the available local skills.

## Boundaries

Do not infer a working product, supported platform, scheduling or financial
integration, production guarantee, or child-repository implementation from
the project name or planning material alone.

See `AGENTS.md` for evidence, maintenance, and validation rules.
