# Icon Maker image output

Version 0.7.3 [indexes both visual companions](knowledge-index-additions.json)
alongside the 20 original knowledge uploads so either file can be discovered by name.

Hosted Icon Maker v0.7.2 includes the [rendering instructions](instructions-addendum.md) and an [accessible description of the Personal Librarian example](personal-librarian-visual-description.md). The instructions call for complete SVG artwork in the same response when image generation is unavailable.

Open the [standalone Personal Librarian SVG](personal-librarian-fallback.svg) in a browser or vector editor. Its `object` group contains the card file. The butterfly, full-width stripes and cream wordmark have separate groups. The SVG includes its own accessible title and description.

The [original PNG](../../plugin/skills/instructions/references/02a%20Glee-fully%20Square%20Personal%20Librarian.b.png) and its November 24 migration package preserve the original release. The SVG was derived from that image and rendered locally at 512 × 512 pixels for visual verification.
