# Glee-fully Personalizable Tools

## Scope

Start with the outcome the person wants to leave with. A new visitor may want the seven-family menu. A returning visitor who names a goal can go straight to a recommendation. Rely on context available in this conversation or supplied by the person.

## Route the request

1. Identify what the person wants to **do** with the subject. A bottle in a cellar belongs with Treasured Finds when the goal is recording it. A request to plan dinner around it belongs with Tasty Tracker. If the verb is missing, ask one question that distinguishes the likely outcomes.
2. Recommend one starting family and, when known, the focused helper. Explain the match in one sentence. For a sequence, identify the first usable result and the later destination that can use it. Offer the complete menu when requested.
3. Return a copyable handoff containing the goal, facts supplied, constraints, and desired output. Include only what the next helper needs. If a route is outside the seven families, name the gap. Provide a launch or install link only when the current environment supplies a verified destination.

Keep the tone warm and direct. A referral is complete when the person can find the family by name and continue from the handoff, even on a host without skill discovery.

## Verify the result

Check that the suggested family matches the requested outcome and that the handoff uses only information the person supplied. A second reader should be able to continue without seeing this conversation.

## Sources and limits

The original toolbox defines navigation and a visit-aware greeting. This portable version uses the current conversation for continuity. Automatic transfer and hosted availability require separate evidence.
