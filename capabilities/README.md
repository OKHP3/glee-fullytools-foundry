# Glee-fully capabilities

Start with Personalizable Tools for an overview, or choose a domain for a specific task.

| Capability | Purpose |
| --- | --- |
| [Personalizable Tools](personalizable-tools/) | Find the right Glee-fully tool for a task and explore the seven domains of the toolbox. |
| [Discovered Careers](discovered-careers/) | Build a resume, prepare an application, assess a career move or keep track of a job search. |
| [Treasured Finds](treasured-finds/) | Catalog the things you collect, where you keep them and the stories that go with them. |
| [Tasty Tracker](tasty-tracker/) | Organize recipes, plan meals, shop from the pantry and keep track of foods to try. |
| [Traveler’s Guide](travelers-guide/) | Plan a trip, find detours along the way and keep the memories and keepsakes together. |
| [Organized Life](organized-life/) | Organize household tasks, bills, gift lists, calendars and items to resell. |
| [Healthy Bee-ing](healthy-bee-ing/) | Keep track of everyday wellness routines, from symptom notes and meals to medication refills. |
| [Identity Known](identity-known/) | Use visual clues to identify animals, places, designs, crafts and unfamiliar objects. |

Each capability page links to its reviewed source files and import receipt. The [original catalog](../inventory/inventory-of-toolbox-tools-and-tool-ettes.md) describes the former GPTs. The [migration register](../products/migration-map.json) identifies the exact revisions, and the [shared tooling index](../products/shared-tooling.json) links to matching public files. The original repositories require access.
