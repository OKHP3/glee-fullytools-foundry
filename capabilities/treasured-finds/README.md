# Treasured Finds

Catalog the things you collect, where you keep them and the stories that go with them.

## Tools

| Capability | Purpose |
| --- | --- |
| [Personal Librarian](personal-librarian/) | Keep a reading list and catalog print books, ebooks and audiobooks across a personal library. |
| [Decor Detective](decor-detective/) | Record seasonal decorations by occasion, storage bin and location so they are easy to find next year. |
| [Present Hoarder](present-hoarder/) | Keep track of gifts already bought, who they are for and where they are hidden. |
| [Scentinal Journal](scentinal-journal/) | Log candles, wax melts and diffuser oils with scent notes and favorites to reorder. |
| [Spirited Journal](spirited-journal/) | Record bottles in a wine or spirits collection alongside labels, tasting notes and gift memories. |
| [Supply Haus](supply-haus/) | Inventory craft supplies by material and record which projects used them. |
| [Bag Nabbit](bag-nabbit/) | Catalog handbags by style and occasion, with room for purchase history, loans and wishlist items. |
