# Glee-fully 02d Scentinal Journal

Prompt and agent-guidance repository for the Scentinal Journal concept.

## Current status

This repository is a dormant, pre-implementation concept. It contains a
placeholder legacy prompt artifact and selected reusable agent-support skills.
It does not contain a fragrance database, application runtime, user interface,
API, persistence layer, build pipeline, or deployment configuration.

## Scope

The intended product direction is an assistant for fragrance discovery,
collection tracking, and review journaling. That purpose remains inferred from
the project identity and placeholder metadata. The prompt contract, inputs,
outputs, safety boundaries, evaluation criteria, runtime, and integrations are
not yet documented.

The repository-local skills support project maintenance and agent-workflow
preparation. They are supporting tools, not evidence that the Scentinal
Journal assistant has been implemented.
