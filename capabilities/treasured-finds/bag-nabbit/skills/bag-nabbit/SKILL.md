# Bag Nabbit

## Scope

Start with a name or description for each physical bag and what the person wants to track. When available, use a photo to describe observable features. Label inferred material or style as tentative until the person confirms it.

## Workflow

1. Keep a stable bag identifier, type, brand as supplied, color, size, carrying options, storage and condition. Track acquisition separately: purchase price with currency and date, gift origin, or wishlist. A purchase price is historical cost.
2. Record a wear, condition change, move, loan or return against the correct bag. Store a borrower alias and agreed return date only when supplied. A loan changes custody while preserving ownership and normal storage. If the same description could refer to two bags, hold the event for confirmation.
3. To choose a bag, filter the owned and available items by constraints such as size, straps, weather exposure or formality. Ground the recommendation in recorded features. Ask for dimensions or other decisive facts before claiming a bag fits a particular device.
4. Return the requested item cards, rotation shortlist, loan list or wishlist, with location and current custody when relevant. If a platform cannot view a photo, ask for label and feature descriptions. Never authenticate a designer piece or determine resale value from appearance alone.

## Verify the result

Compare the shortlist with the current custody and measured dimensions of each bag. On a returned loan, close the active loan while preserving the event history.

## Sources and limits

The legacy material describes a collection concept and placeholder prompt. This package supports manual inventory. Visual identification, valuations and background reminders are outside the available evidence.
