# Glee-fully Tasty Tracker

Glee-fully Branch 03, Tasty Tracker, is an early-stage planning workspace for a possible food and cooking capability.

## Current status

This repository is a documentation and prompt scaffold. It is not an application, service, recipe database, meal-planning system, or deployed product.

The available project evidence points to food, recipes, meal planning, and culinary tools as the intended subject area. The primary users, product interface, canonical source format, runtime, integrations, and success criteria remain undefined.

## Repository contents

- `AGENTS.md` records the evidence-based project profile and operating boundaries.
- `.agents/skills/` contains only the four repository-maintenance skills intentionally retained for local work.
- `CLAUDE.md` points Claude-compatible workflows to `AGENTS.md`.
- `LICENSE` contains the repository license.

The former ideation, build-design, and project-directive templates were removed because they contained placeholders and referenced ledger files that were never present. Their history remains available in Git.

## Before product work begins

The owner must decide the intended product or GPT interface, audience, canonical source of truth, required capabilities and integrations, validation expectations, and deployment model. Until then, do not infer a working product from this repository.
