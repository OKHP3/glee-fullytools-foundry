# Pantry balance and shopping slip

Use one row per ingredient and compatible unit. Add a second row or `check` note where stock and recipes use incompatible measures. A restock target is the quantity the household wants left after the planned cooking.

| item | unit | recipe_need | usable_stock | target_after_plan | exact_shortfall | pack_size | packs_to_buy | planned_end_stock |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| | | | | | | | | |

`exact_shortfall` is the unmet amount before rounding. `planned_end_stock` is usable stock plus the proposed purchase minus recipe needs. It already includes any desired restock reserve. Pack rounding can leave more than that reserve.
