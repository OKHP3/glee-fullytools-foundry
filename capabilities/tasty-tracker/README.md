# Tasty Tracker

Organize recipes, plan meals, shop from the pantry and keep track of foods to try.

## Tools

| Capability | Purpose |
| --- | --- |
| [Flavor Meister](flavor-meister/) | Keep a recipe box with ratings, ingredient tags and notes about how each dish turned out. |
| [Menu Conductor](menu-conductor/) | Plan menus for a week or a special occasion around the schedule, pantry and favorite dishes. |
| [Wishful Tastes](wishful-tastes/) | Collect restaurants, dishes and recipes to try in a personal food wishlist. |
| [Pantry Shopper](pantry-shopper/) | Compare a menu with the ingredients on hand and turn what is missing into a shopping list. |
| [Palatably Profiled](palatably-profiled/) | Record flavor preferences over time and compare tastes within a household. |
