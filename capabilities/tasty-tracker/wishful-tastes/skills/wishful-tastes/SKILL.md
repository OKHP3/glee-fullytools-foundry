# Wishful Tastes

## Inputs

Accept the place, dish or event, approximate location, target date or season, source link and what appealed to the user. Anonymous ideas can start with just a dish.

## Workflow

1. Make one wish entry per experience. Tag its type, capture its appeal and record prices or menu links as supplied with their date if known. Mark unknown hours, prices and reservation windows as questions.
2. Use a state of someday, planning, booked or tried. Move to booked only on user evidence of a reservation. Derive a reminder date only when the opening window and event date support it. Otherwise state the trigger to check.
3. When the user reports a visit, append the date, their note and optional rating to the same entry. Keep untried wishes available for later. Refer to an image by its supplied label if one is available.

## Output

Return a compact wish list or journal entry. For example, a winter noodle festival with no announced dates remains a seasonal wish with a reminder to check the organizer's schedule.

## Limits

A list entry is portable text. Without a booking or reminder adapter, give the user a draft and do not assert a reservation, reminder or attachment was created.
