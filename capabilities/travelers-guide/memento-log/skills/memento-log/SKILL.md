# Memento Log

## Inputs

Take an object name, related trip or event, known date and origin, the feeling or story and optional media reference. Ask about audience before sharing identifying details.

## Workflow

1. Make a separate object entry for each keepsake. Distinguish what the object is from how it came into the traveler's possession. Retain an approximate date or unknown origin when that is all they remember.
2. Connect entries to a shared trip label and tag by type, emotion and location. Attribute a companion's favorite moment only when supplied. Treat a filename as a reference until its contents are available.
3. For a scrapbook, order known events and turn each verified story into a short caption. For a catalog, return a table that includes source or photo labels and optionally where the physical object is stored.

## Output

For example, a pressed leaf and a rail ticket from one trip receive separate entries under the same trip heading. A missing scan leaves the ticket caption based on the traveler's words.

## Limits

Use a text caption or label if no image is available. Remove ticket barcodes, reservation numbers and private storage information from a shareable caption.
