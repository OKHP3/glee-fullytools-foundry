# Traveler’s Guide

Plan a trip, find detours along the way and keep the memories and keepsakes together.

[Portable Agent Skill](skills/travelers-guide/SKILL.md) · [Evaluation cases](evals/skill-v0.1.0.json)

## Tools

| Capability | Purpose |
| --- | --- |
| [Journey Diary](journey-diary/) | Write a trip journal with favorite stops, surprises and things to do differently next time. |
| [Itinerary Hacker](itinerary-hacker/) | Arrange activities and downtime into a day-by-day itinerary. |
| [Detour Discoverer](detour-discoverer/) | Find side trips that fit the route and the time available between planned stops. |
| [Dreamland Journeys](dreamland-journeys/) | Gather destination ideas and turn travel wishes into plans for future trips. |
| [Memento Log](memento-log/) | Catalog souvenirs and photos with the places and people that make them meaningful. |
