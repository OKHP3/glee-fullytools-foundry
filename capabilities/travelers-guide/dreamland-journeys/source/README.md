# Dreamland Journeys

Dreamland Journeys is a content-first Glee-fully Tool-ette scaffold for
capturing aspirational travel ideas and shaping them into organized dream-trip
entries.

## Start here

- [Tool-ette instructions](prompts/dreamland_journeys_instructions.md)
- [Capability specification](specifications/dreamland_journeys_pme.yaml)
- [Tool-ette summary](docs/dreamland_journeys_toolette_summary.md)
- [Mood and destination references](references/dreammood_tags.csv)
- [Status-entry template](templates/status_snapshot_template.md)

## Repository map

- `prompts/`: persona, tone, and reverse-dream prompt material.
- `specifications/`: declared Tool-ette capabilities and triggers.
- `docs/`: product summary and relationship notes.
- `references/`: mood, destination, and moodboard seed material.
- `templates/`: reusable dream-trip status-entry structure.
- `.agents/`: repository-local Agent Skills and supporting tooling.
- `skills/`: the maintained publication mirror for the skill-promotion package.

## Status and boundaries

This repository is a content scaffold. It contains no executable application,
runtime configuration, persistence layer, deployment configuration, booking
integration, or verified live travel-data connection.

The repository preserves imaginative travel ideation separately from factual,
current, or safety-sensitive travel guidance. Such guidance would require
fresh, attributable sources before being treated as authoritative.
