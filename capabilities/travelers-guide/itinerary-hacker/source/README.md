# glee-fully-gpt04b-itinerary-hacker

This repository currently contains a governed local Agent Skill corpus and
promotion workspace. It does not currently contain an itinerary application,
travel-planning prompt, runtime, interface, data source, or deployment target.

## Start here

- [AGENTS.md](AGENTS.md): canonical repository guidance and authority model.
- [.agents/skills/README.md](.agents/skills/README.md): generated catalog of the
  46 local skill packages.
- [.agents/skills/](.agents/skills/): editable/runtime skill sources.
- [skills/](skills/): publication mirrors where a promotion relationship has
  been established.

## Project meaning and status

The repository name identifies Glee-fully Branch 04b as an intended GPT
Tool-ette for trip itinerary optimization and activity scheduling. That purpose
is inferred from the project identity and earlier guidance. The current tracked
content instead consists of reusable Agent Skills, package resources, tests,
catalog metadata, and historical evaluation evidence.

The intended user, final artifact type, relationship to the Travelers Guide
project, and any future itinerary runtime remain to be confirmed. No current
skill package should be treated as proof that the itinerary product exists.

## Package surfaces

`.agents/skills/<name>/` is the editable source while a skill is being
developed. A matching `skills/<name>/` directory is a publication mirror only
when its promotion records establish that relationship. Historical benchmarks
are version-specific evidence and do not validate newer releases.
