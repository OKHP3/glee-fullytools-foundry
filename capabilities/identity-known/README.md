# Identity Known

Use visual clues to identify animals, places, designs, crafts and unfamiliar objects.

## Tools

| Capability | Purpose |
| --- | --- |
| [Critter Spotter](critter-spotter/) | Use a photo to identify an animal and describe the features that distinguish it. |
| [Roost Wrangler](roost-wrangler/) | Identify architectural and furniture styles from details in a photo. |
| [Sight Seeker](sight-seeker/) | Identify landmarks, landscapes and objects in the night sky from visual clues. |
| [Snap Decoder](snap-decoder/) | Interpret saved screenshots, from a quote worth keeping to an unfamiliar error message. |
| [Motif Muse](motif-muse/) | Identify color palettes and patterns in a design and save them as reusable style references. |
| [Maker Matcher](maker-matcher/) | Identify the craft behind a handmade object from its tools, materials and techniques. |
| [Self Fixer](gpt07g-self-fixer/) | Identify an unfamiliar part or connector from a photo and describe what it does. |
