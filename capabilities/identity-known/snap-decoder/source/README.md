# glee-fully-gpt07d-snap-decoder

## Current state

This repository is a pre-implementation scaffold for Glee-fully 07d, Snap
Decoder. Its declared product purpose is image content analysis and object
identification, but no product runtime, interface, model integration, or
deployment configuration is present.

The current checkout also contains a retained Agent Skills workspace under
`.agents/skills/`, including reusable authoring, migration, governance, and
validation skills. Those skills are repository tooling and are not evidence
that Snap Decoder has been implemented. `skills/okhp3-skill-promotion/` is the
single reviewed publication-mirror package currently present.

## Start here

- Read [AGENTS.md](AGENTS.md) for the evidence-backed project profile,
  operating boundaries, and available checks.
- Browse the generated [skill catalog](.agents/skills/README.md) when working
  on the retained Agent Skills workspace.
