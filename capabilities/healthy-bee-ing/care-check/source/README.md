# Glee-fully GPT06a Care Check

## Purpose

This repository records the documentation and agent resources associated with
Glee-fully Branch 06a, Care Check.

The existing project description presents Care Check as a personal health
check-in and symptom-logging assistant. The wider Healthy Bee-ing pulsebook
places it alongside sibling tools for stress, nutrition, medication, mood,
hydration, and midlife support.

## Current status

Confirmed: this checkout is a documentation and Agent Skills repository.

Unknown: the current Care Check prompt, runtime behavior, deployment status,
target audience beyond the owner, data handling, acceptance criteria, and
safety review.

This repository does not currently contain a Care Check application runtime,
test suite, deployment configuration, or verified production implementation.
Health-related guidance must not be treated as diagnosis or a substitute for
professional medical care.

## Repository map

- `docs/healthy-bee-ing-pulsebook-2025-09-01.md`: historical suite and
  sibling-branch context. It is not a Care Check implementation specification.
- `.agents/prompts/`: project onboarding and migration prompts.
- `.agents/skills/`: checked-in Agent Skill packages and their generated
  catalog.
- `AGENTS.md`: canonical repository guidance.
- `CLAUDE.md`: compatibility pointer to `AGENTS.md`.

## Boundaries

Do not infer deployment, clinical capability, privacy properties, or complete
product behavior from the project name, pulsebook, or checked-in skills. Treat
the pulsebook as historical context and the Agent Skills as supporting
resources, not proof of a Care Check runtime.
