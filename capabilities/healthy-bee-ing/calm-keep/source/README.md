# Glee-fully GPT06b Calm Keep

Calm Keep is a documentation-first repository for a proposed Glee-fully
wellness companion focused on stress, rest, sleep, and everyday balance.

## Current status

The repository does not contain an application, executable routing, deployment
export, authoritative Calm Keep prompt, or direct Calm Keep pulsebook. The
product purpose and mission remain inferred from the repository identity and
related Healthy Bee-ing lineage.

The repository also carries a broad local Agent Skills workbench. Those
reusable skills are tooling assets, not evidence that Calm Keep itself is
implemented or deployed.

## Repository map

- `.agents/skills/` contains active local Agent Skills, references, fixtures,
  scripts, tests, and generated catalog metadata.
- `skills/okhp3-skill-promotion/` is the managed publication mirror for the
  local `okhp3-skill-promotion` package.
- `archive/parent-context/` contains historical parent-level Healthy Bee-ing
  material. It is lineage, not a Calm Keep specification.
- `AGENTS.md` is the canonical operating guide.
- `CLAUDE.md` points Claude-based tooling to `AGENTS.md`.

## Boundaries

Calm Keep should remain distinct from Healthy Bee-ing and sibling wellness
tools. Future wellness content must be supportive and non-diagnostic. It must
not present itself as medical advice, diagnosis, treatment, or emergency
response.

Do not describe Calm Keep as live, medically validated, or production-ready
without new direct evidence.

## Validation

This is not a conventional application repository. Use the repository checks
documented in `AGENTS.md` and the relevant local skill package instructions.
