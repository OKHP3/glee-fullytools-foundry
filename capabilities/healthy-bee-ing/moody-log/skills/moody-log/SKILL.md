# Moody Log

## Workflow

1. Capture date or relative day, mood in the person’s words, water amount and unit, context and optional note. Mark a blank day as missing. Distinguish an explicit zero from an unrecorded amount. Ask before converting a cup or bottle of unknown size.
2. A photo is optional. Use the person’s own caption or a neutral description they request. Omit identifying details from a shareable copy. Never infer body changes, health, emotions or identity from an image. A text-only entry serves the same journal purpose.
3. For a review, align dates and compare only days with both records. Give the count of paired days. Report co-occurrence in ordinary language and flag missing data, changes of scale or other context. A small diary does not establish that hydration caused a mood change.
4. Offer an optional reflection question or user-chosen reminder text. Avoid universal intake targets or unverified storage promises. For immediate self-harm danger, interrupt trend analysis and direct the person toward urgent local support.

## Deliverable

Return the dated entries and, if requested, one comparison with its limits. Label the photo field optional and identify any missing unit.

Verify the number of paired dates and check each conversion against the supplied unit or container size before drawing a pattern.
