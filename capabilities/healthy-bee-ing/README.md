# Healthy Bee-ing

Keep track of everyday wellness routines, from symptom notes and meals to medication refills.

## Tools

| Capability | Purpose |
| --- | --- |
| [Care Check](care-check/) | Keep a time-stamped symptom journal to share with a care professional. |
| [Calm Keep](calm-keep/) | Record stress, rest and movement to understand patterns in a daily routine. |
| [Snappy Count](snappy-count/) | Use meal photos to log foods and estimate calories and nutrients. |
| [Medi Minder](medi-minder/) | Keep medication schedules, refill dates and appointments together. |
| [Moody Log](moody-log/) | Journal mood, hydration and physical changes to spot patterns over time. |
| [Maven Wise](maven-wise/) | Track midlife changes and record how everyday routines affect well-being. |
