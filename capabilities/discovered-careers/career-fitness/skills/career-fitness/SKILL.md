# Career Fitness

## Scope

Start with a target role or two plausible directions, examples of past work, and the constraints that matter to the person, such as location, time, pay or schedule. If the person has no target, describe a small set of role hypotheses based on the activities they want to do more often.

## Workflow

1. Turn each work example into a capability with context. Distinguish observing, assisting, delivering independently and owning decisions. Ask for evidence behind a self-rating when it would change the recommendation.
2. Use an actual role description if provided. Otherwise label requirements as typical or inferred and invite a real posting. Compare each critical requirement with demonstrated, adjacent or missing evidence. Keep preferences distinct from deal-breakers.
3. Recommend a realistic first target or explain the tradeoff between targets. Pick one meaningful gap, a low-cost practice task and a tangible artifact or result that would demonstrate progress. Add a checkpoint tied to the person's available time.
4. For pay, record role level, geography, currency, compensation type, source and date. Compare like with like. When suitable current figures are unavailable, provide a comparison template. Recommend a certification only if its connection to the target is supported.

Return a role comparison, the evidence behind the recommendation and the next experiment. Leave unknown qualifications explicit.

## Make the choice visible

Start the comparison with the person's non-negotiable constraints. For each role, mark whether the posting meets each constraint, conflicts with it or leaves it unknown. A role that conflicts with a firm constraint can still inform a learning plan. Present it as an alternative only if the relevant constraint changes. Distinguish an entry-level hiring requirement from a skill that could be developed after starting.

Place each target beside an example from the person's work. For instance, demonstrating a procedure to new colleagues supports explaining that procedure. Designing a training curriculum calls for separate evidence. If the user supplied only a target title, offer plausible tasks to verify against an actual posting and label them as hypotheses.

For a stated pay floor, identify which portion of a comparable posted range, if any, qualifies. If only the upper end qualifies, give the intersection and a question to confirm the likely offer. Use the pay labels in `references/role-comparison-worksheet.md` when available. Keep advertised ranges, observed market distributions and personal pay targets distinguishable. A valid percentile needs distribution data.

## Turn a gap into a decision

Give a short recommendation with the facts that could reverse it. Pick one missing capability on the recommended path and return a practice task, inspectable work sample, success check and time commitment. When recommending a course, name the skill to practice and how the person can demonstrate it afterward. Verify a named credential is required or preferred before making it a priority.

When the person changes their floor, schedule or availability, recalculate every affected comparison and give them the revised recommendation and next experiment. Keep prior work evidence and posting facts intact.

## Verify the result

For each recommended role, point to one supplied work example and one uncertainty or growth opportunity. Reconsider the recommendation if it conflicts with a stated deal-breaker.

## Sources and limits

The repository describes a fit-assessment concept and has no validated scoring algorithm. The comparison is advisory. Salary figures need current, geographically relevant evidence.
