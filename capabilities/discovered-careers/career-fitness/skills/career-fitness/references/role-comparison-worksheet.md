# Career comparison worksheet

Fill one row for each target role. Use the same work location, currency, pay period and compensation type when comparing money. A posted range describes one vacancy. Market percentiles require a dated distribution for comparable workers.

| Role and source | Non-negotiable constraints | Work already demonstrated | Skill to test | Pay range and floor | Recommendation |

| Role title, level, posting date | Pass, fail or unknown for each | Action and scope from the person's example | Name a real task in the posting | Include units and one label below | Pursue, investigate or set aside, with reason |

## Compare a pay floor

For a comparable advertised minimum and maximum, use the first applicable label.

| Label | Condition |
| --- | --- |
| Entire range below floor | Advertised maximum is below the person's floor. |
| Entire range meets floor | Advertised minimum is at or above the floor. |
| Part of range meets floor | The floor is above the advertised minimum and at or below its maximum. Ask which part of the range the employer expects to offer. |
| Pay not comparable | Location, currency, time basis, compensation type or the range is missing or incompatible. Record what would resolve it. |

A range ending exactly at the floor qualifies only at its ceiling. A bare range provides neither a median nor a guaranteed offer.

## Plan one experiment

| Practice task | Work sample | Success check | Time available |
| --- | --- | --- | --- |
| Do one activity that represents the missing skill. | Name a result someone can inspect. | State an observable condition for completion. | Set a duration or checkpoint the person can meet. |

Example: a coordinator exploring training work can write a five-step process lesson. A peer should be able to complete the task from the lesson in one sitting. Record which instructions the peer needed clarified. This gives evidence of lesson design and testing. It establishes no certification.
