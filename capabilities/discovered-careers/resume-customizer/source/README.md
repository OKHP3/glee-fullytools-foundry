## Status

The repository currently contains anonymized resume examples, professional-summary
tone examples, industry keyword references, and local Agent Skills. It does not
currently contain a user interface, executable tailoring engine, ATS scorer,
document exporter, or deployment configuration.

The intended workflow is inferred: use an existing resume and a target job
description to produce a credible, keyword-aware, appropriately toned revision.
