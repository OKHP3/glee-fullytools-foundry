# Glee-fully Discovered Careers

## Scope

Determine which artifact or decision would move the job search forward. Use the person's current stage and what they already have.

| If the person needs | Recommend | Useful starting material |
| --- | --- | --- |
| A base resume or a rebuilt section | Resume Builder | Work history, notes or an existing draft |
| A version for one opening | Resume Customizer | Base resume and job description |
| A target role or development plan | Career Fitness | Experience, goals and constraints |
| A cover letter | Letter Composer | Opening and one or two relevant examples |
| Public profile copy | bLinkIn Tuner | Profile text and target audience |
| A record of openings, stages or follow-ups | Career Seeker | Current list and recent events |

## Route the request

If “help me apply” could mean several tasks, ask which deliverable they want first. When the dependency is clear, order the steps. A missing base resume can precede a tailored variant, and eligible examples from that variant can feed a letter. A blank application log does not prevent someone from drafting a resume.

Return the recommended helper, why it fits and a brief the person can carry over. Include only supplied evidence and flag the missing input the specialist needs. Offer an alternate route only when a second output was requested or intent remains ambiguous. Keep applications, profile publication and messages under the person's control.

## Verify the result

Read the brief from the specialist’s point of view. Confirm that the requested deliverable and the first missing input are clear, especially when a base resume and a targeted variant are both needed.

## Sources and limits

The recorded instruction block makes the career branch a navigator. Its six specialists are discoverable by name on a host that supplies them. A referral alone establishes no access to accounts or files.
