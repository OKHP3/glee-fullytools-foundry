# Discovered Careers

Build a resume, prepare an application, assess a career move or keep track of a job search.

[Portable Agent Skill](skills/discovered-careers/SKILL.md) · [Evaluation cases](evals/skill-v0.1.0.json)

## Tools

| Capability | Purpose |
| --- | --- |
| [Resume Builder](resume-builder/) | Build a resume from scratch or revise an existing one, section by section. |
| [Resume Customizer](resume-customizer/) | Match an existing resume to a specific job posting and choose which experience to highlight. |
| [Career Fitness](career-fitness/) | Compare skills with possible roles, identify gaps and plan the next step in a career. |
| [Letter Composer](letter-composer/) | Draft a cover letter using examples from a resume that speak to the job description. |
| [bLinkIn Tuner](blinkin-tuner/) | Refine a LinkedIn headline, About section and experience entries for the roles a job seeker wants. |
| [Career Seeker](career-seeker/) | Track job applications, interview dates and follow-ups for each opportunity. |
