# Glee-fully GPT01A Resume Builder

## Status

This repository is an incomplete, content-only prototype and sample library for a GPT-assisted resume workflow. It does not contain an executable application, prompt runtime, resume generator, test harness, deployment configuration, or production service.

## Purpose

The repository preserves reusable resume-workflow inputs and examples:

- `inputs/` contains candidate-career schemas, including the main template and a separate checkpoint format.
- `references/` contains editorial tone guidance and a small industry-keyword reference table.
- `examples/` contains anonymized sample-library notes and resume presentation examples.
- `.agents/` contains repository-local Agent Skills and support tooling. It is infrastructure for working with the repository, not the resume-builder runtime.

## Start here

1. Use `inputs/resume-schema-template.md` for the main career-data workflow.
2. Use `inputs/resume-checkpoint-schema.md` only when the alternate checkpoint format is intentional.
3. Consult `references/` for tone and keyword guidance.
4. Review the examples in `examples/resumes/`.

The two resume example families are intentionally distinct. The primary examples use the Blue Horizon/Skyline sample history. The checkpoint examples use the BrightMedia/Sunrise sample history. Do not treat either fictional dataset as real candidate information.

## What is not demonstrated

The repository does not demonstrate automated data ingestion, prompt execution, DOCX generation, ATS scoring, web or API delivery, persistence, or production guarantees. The DOCX files are checked-in examples, not outputs generated by a repository command.

## Validation

There is no build or test command. For documentation-only changes, use `git diff --check`. YAML and DOCX integrity checks are described in `AGENTS.md`.
