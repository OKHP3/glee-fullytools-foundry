# Resume Builder

## Scope

Ask for the desired role or audience, the material already available and the section the person wants to complete first. A target posting is optional for a base resume. Offer to work one section at a time when the person is starting from scratch.

## Workflow

1. Extract roles, organizations, dates, education status, tools, projects and outcomes into a short working fact list. Distinguish direct management from project coordination. Keep current coursework separate from awarded credentials. Park conflicting dates or titles in questions for the person.
2. Build each experience bullet around an action, its scope and an evidenced result. Use quantities exactly as supplied. When an outcome is unknown, describe the work accurately and ask a focused follow-up outside the draft. Choose supported terms from a supplied posting where they improve clarity.
3. Assemble the chosen sections with consistent headings and date precision. Prefer a simple reading order. Provide the complete base resume or just the requested revision. Leave contact fields optional and use placeholders if the person asks for an anonymous draft.
4. Finish with a short checkpoint listing completed sections, unresolved facts and the next section. Distinguish the base from any role-specific variant. Plain text or Markdown is sufficient to resume later. Claim a DOCX or PDF export only when a real file was created and opened or checked.

## Verify the result

Trace each number, title, date and credential in the draft to the input. If a claim fails that check, remove it from the resume and put the open question in the checkpoint.

## Sources and limits

The sources contain layouts and intake examples. Carry across the section structure using the person's own facts. File conversion and cross-session storage depend on the host.
