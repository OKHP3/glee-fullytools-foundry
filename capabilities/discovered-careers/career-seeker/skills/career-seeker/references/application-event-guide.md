# Application event guide

Keep the event record separate from the current stage. A candidate can reschedule an interview twice while the application stays at the same stage.

| Confirmed event | Current stage | Date or action to keep |
| --- | --- | --- |
| Posting saved | Saved | Add the closing date if the posting supplies it. |
| Application submitted | Applied | Record the submission date. |
| Interview scheduled | Interviewing | Record when the invitation arrived and the future meeting date separately. |
| Interview rescheduled | Interviewing | Preserve the superseded meeting date in the history. Show only the replacement as the upcoming meeting. |
| Interview completed | Interviewing | Record the actual meeting date. Add a follow-up only when its date is known or the user wants a proposed date. |
| Offer received | Offer | Record offer date and decision deadline separately. |
| Employer declined | Declined | Record the employer's decision date if known. |
| Candidate withdrew | Withdrawn | Record the candidate's withdrawal date if known. |

Use the requisition ID when supplied. Employer and role help distinguish openings when no ID is available. A repeated report of the same event is one event. Ask before merging records with conflicting IDs.

## Count interview progress

For “interviews completed per application,” count distinct opportunities with at least one completed interview among the opportunities with confirmed submissions in the chosen cohort. Divide by the number of those submitted opportunities. Use submission date to define a time-limited cohort. Report numerator, denominator and cutoff or window. An invitation, a rescheduled appointment or a saved posting alone adds nothing to the numerator. When there are no applications, report zero submitted and the rate as undefined.

If the person wants invitations per application or still-active opportunities, name that different measure and define its denominator. For reminders prepared in chat, include the due date and exact opportunity for the person to copy.
