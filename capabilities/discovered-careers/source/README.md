# glee-fully-gpt01-discovered-careers

Documentation repository for the Discovered Careers branch of the Glee-fully Personalizable Tools suite.

The project describes a career-navigation GPT concept that identifies a user's career task and routes them to a more specialized sibling Tool-ette, such as resume building, resume customization, career fitness, letter composition, LinkedIn optimization, or job-search tracking.

This checkout contains prompt and product-design artifacts only. It has no executable application, runtime, deployment configuration, or verified external integrations. Start with [AGENTS.md](AGENTS.md) for repository guidance and the [pulsebook](docs/discovered-careers-pulsebook.md) for the primary design record.
