# Hosted GPT plugin index

Find the public plugin files for each of the 53 Glee-fully GPTs migrated in the owner’s ChatGPT workspace. Fifty had their own GitHub repositories. Glee-fully Icon Maker, Glee-fully Grounded and a second Healthy Bee-ing GPT were identified through My GPTs.

## Read or download a plugin

For observed behavior in ChatGPT and changes made after migration, see the [runtime test report for all 53 private plugins](hosted-plugin-runtime-tests.md).
For the 14 completed workflows, see their [current releases and acceptance results](workflow-acceptance.md).

Open a package ID to browse its FoundRy directory. **Instructions** opens the migrated skill. **Starters** opens the full list of conversation starters from the original GPT Builder. **Manifest** opens the public plugin metadata, including its display name, description and native default prompts. The [tagged release](https://github.com/OKHP3/glee-fullytools-foundry/releases/tag/hosted-gpt-plugins-2026-11-24) provides one downloadable ZIP per package. To find a ZIP, search the release assets for the package ID followed by `-former-gpt-`.

For the 50 former repositories, the capability’s adjacent `source/` directory preserves its tracked GitHub files. Its `skills/` directory holds the separately authored portable skill. The [repository migration map](migration-map.json) records those 50 source revisions. The [legacy content inventory](legacy-content-inventory.json) records the evidence available from the former GPTs.

## What survived migration

All 53 original Builder instruction bodies matched the corresponding native skills after removing the skills’ YAML frontmatter. Across those GPTs, Builder showed 278 conversation starters. The native manifests expose 106 of them. Each ZIP includes its full public list in `foundry/builder-starters.json`. These lists preserve 276 starters verbatim and generalize the recipient names in two examples. Seventeen GPTs had zero starters, and their lists are empty. [Builder and native migration evidence](legacy-content-inventory.json).

## Knowledge files

The letters in the table stand for **E** (exact source bytes), **D** (reviewed public derivative) and **O** (omitted). Select a count to open the package receipt for filenames, SHA-256 hashes, public editions and omission reasons. All 228 upload names shown in Builder matched the corresponding native plugin references. The public packages contain 157 byte-for-byte copies and 70 reviewed public editions. The Self Fixer receipt records the one file withheld for private correspondence. A shared file counts once for each GPT that used it. One GPT had no knowledge uploads.
